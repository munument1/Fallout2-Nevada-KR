# 네바다 한국어 완성형 패키지

Nevada Extended용 한국어 번역과 출력 파일을 함께 구성한 클래식 실행판입니다.

## 설치

1. 게임을 종료합니다.
2. ZIP 안의 파일과 폴더를 네바다 설치 폴더에 모두 덮어씁니다.
3. `Nevada.exe` 또는 고해상도 실행 파일 `NevadaHD.exe`를 실행합니다.

한국어 설정과 글꼴은 미리 적용되어 있습니다. 원하면 덮어쓰기 전에 기존 파일을 백업해 두세요.

## 적용 내용

- 기존 네바다 한국어 번역 데이터
- 한국어로 설정된 `Nevada.cfg`
- 일반판·HD판의 한국어 출력 연결
- 본문 돋움 11, 버튼 카페24 아네모네 에어 16·굵게
- 네바다 동봉 sfall용 실행 파일 등록과 한국어 메시지 설정

기존 Nevada Extended와 함께 제공된 sfall 및 고해상도 패치 파일을 사용합니다.
글꼴 배포 라이선스는 `fonts` 폴더에 있습니다.

## 확인 범위

일반판·HD판의 글꼴 DLL 로딩과 등록, 실행 파일 패치 범위, 한국어 설정, 번역 파일 보존 및 ZIP 무결성을 검사합니다. 전체 퀘스트·저장/불러오기·장시간 플레이의 전수 검증은 포함하지 않습니다.
